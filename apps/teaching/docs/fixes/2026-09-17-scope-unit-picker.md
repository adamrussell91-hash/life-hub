# Scope unit picker correction

The Scope and Sequence Add Unit picker must only offer active units which are not already on the timeline.

Inactive units are not selectable. A trashed unit already placed on an existing timeline stays resolvable there so the timeline does not degrade to an unknown record before the teacher removes or replaces the placement.

Picker rows show the unit title with year level, subject, primary term when present, and lesson count so similarly named units are distinguishable.
