# Professional Hub

Read-only Slice 4: Professional Hub shell, People/Organisations search, and
relationship timelines, mounted at `/professional/` in the Life Hub
umbrella.

## Develop

```bash
npm install
npm run dev
```

Local passphrase: `professional-hub-local`.

## Test / typecheck / build

```bash
npm test
npm run typecheck
npm run build
```

See `AGENTS.md` for scope and server contracts.
