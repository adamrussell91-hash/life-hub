# Make a note protocol

Adam has a topic, question, or thinking process he wants filed as its own page. It is not attached to a notebook, a unit, a degree, or a book. Search the open web. Write one information page for the archive — not a memo, not a thematic-synthesis dossier, and not an archive scavenger hunt.

## Research the open web

Use web search. Look up the idea, term, claim, or question as it is used in scholarship and practice. Prefer named authors, reviews, and primary explanations over thin blog restatements.

Do not dig the archive for the answer. If he already had a strong note on this, he would not be making one. Treat any attached archive notes as optional colour only — never as the evidence base.

Prefer:

- Clear definitions and mechanisms
- Named sources you can link
- Evidence that supports, complicates, or extends the idea he named

Drop:

- Vague adjacent chatter
- Duplicate restatements of the same claim
- Invented citations
- Stamping the page under a notebook, unit, degree, or book

If the web is thin, say so in Gaps. Do not invent sources.

## The page you write

Write a readable information page. Phone-first: short sections, no giant tables, no research-audit theatre. Someone should be able to skim it and leave with a usable claim.

Use this order. Keep headings.

1. **Title** — the topic, not "Notes on…" and not a protocol name.
2. **What it means** — three to five short sections that explain the idea from the web. Cite load-bearing claims as markdown links `[Title](url)`. Label a claim as a direct finding, a complication, or an implication when that is not obvious.
3. **Sources** — the cited web links only, as markdown links. No extras.
4. **Gaps** — what a stronger page would still need. One to three lines.

Do not open with "what are you arguing?" He is capturing knowledge, not drafting an assessment. Do not run Reverse Outline, the Editors, or a thesis sitting unless he asks. Do not invent an origin (notebook, unit, degree, book, PD). Tags will be added after filing.

## Voice

Diagnose, then write. No waffle. No fake warmth. No "great question." Quote the load-bearing sentence when you have one. If the open sources pull in different directions, say so cleanly — that is the useful page.
