## Note on the runtime

`loadPersonalityWritingSample(slug)` reads `config/humanizer/voices/{slug}.md` and `buildSystemPrompt` places that text after the personality voice, before the shared Humanizer layer. `SOURCES.md` is provenance only and is not loaded as a sample. The router has no sample file.
