# Scheduling unit lessons

Open a unit, choose its top-right three-dot options menu, then **Schedule lessons**. The unit is already selected. Choose the class and the week, term or custom date range.

The class's saved timetable loads automatically. Edit its day, period, start/end time and room fields, or paste a replacement under **Paste your class timetable** and choose **Use pasted timetable**. Enter one session per line, for example:

```text
Day 1 | P4 | 11:50–12:43 | A0214
Day 2 | P5–6 | 13:24–15:10 | A0214
```

Tabs or commas work too, including separate start/end columns. Period and room are optional. Use 24-hour times, or mark both times with am/pm. Paste only the selected class's sessions; whole-school grids and period-only rows without times need to be rearranged into session rows first. Invalid rows leave the current timetable intact and report the line to fix.

Set the cycle length, anchor date and anchor day for the new timetable. Weekends do not advance the cycle. Add weekday school closures under non-school dates; cycle corrections can reset a day's cycle number.

Choose **Preview lessons**, omit any sessions you do not want, then **Add lessons to calendar**. This saves the editable timetable on the class and creates real lesson drafts for this unit. Other units for the same class can reuse it. Existing calendar sessions keep their saved times when the class timetable changes.
