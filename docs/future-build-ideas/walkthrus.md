# WalkThrus text and SVG collection

**Status:** Collected reference material for future planning. No implementation scheduled.

## Collection

The supplied WalkThrus scans have been transcribed by section and traced into labelled SVG assets.

- [Download the complete SVG collection](https://chatgpt.com/library?file_id=libfile_2644196a0fd88191a7bb75254f79780f&account_id=personal)
- [Read the sectioned text extraction](https://chatgpt.com/library?file_id=libfile_0c96191f479c819198df44aed4ed33a4&account_id=personal)

**Working copy:** the unzipped SVGs live in Adam's Google Drive folder `WalkThrus_SVG_Assets` (subfolders `00_Contents`, `01_Why`, `02_What`, `03_How`, `99_Page_context`). GitHub struggled with the number of files, and the traces copy the book's artwork, so they stay out of this public repository. Read them from Drive, or later from private `life-hub-data`.

These links open the owner's ChatGPT files. They are not public GitHub downloads. The archive itself is stored with the source work, rather than checked into this repository.

## What is included

The archive contains 630 labelled SVG files, organised by section and printed page. It includes illustrations, step panels, diagrams, portraits, menu icons, navigation panels, colour panels and full spread context files. Some files deliberately overlap, so this is not a count of unique original illustrations.

Unzip the archive and open `index.html` for the searchable visual catalogue. The folder also includes `asset_index.csv`, `manifest.json`, `README.md`, `VALIDATION.md` and a preview.

## Source and quality

The source comprises 79 scanned spreads covering printed pages 6 to 163. Printed page 164, References, was not supplied. Some early artwork is physically clipped by the scans.

The SVGs contain vector paths, not embedded raster images. They are cleaned traces from scans, rather than original publisher vectors or manually redrawn masters. Scan imperfections remain. Text within illustrations is outlined rather than editable. Clipped source artwork is flagged in the manifest and was not reconstructed.

The text extraction includes source gap notes. It was visually checked against the supplied spreads, but minor OCR errors may remain.
