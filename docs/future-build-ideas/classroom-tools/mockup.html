What the mockup shows

  • Divider host. The gear sits at the end of the rule at low opacity. Hover or focus lifts it; tapping slides the tool chips out along the line. The first divider opens on the timer so you can see the stack.
  • Tools block. Same toolbox, but it takes a block's slot. The last block on the page opens on the name picker.
  • Stacked timers. Reading 5:00 then Writing 10:00. Each segment has its own colour on the bar, it rolls straight into the next one, and it chimes at each change.
  • Class lists. Each class gets a Students section. Type or paste the list once. The name picker and groups tool open on this lesson's class, and a dropdown switches to any other class. Edits to a list show up in the picker straight away.
  • Skip in picker. Set only in the class's Students section. The picker quietly leaves that student out and never shows a total that would give it away. Try skipping a name, then picking.
  • Sound. Chime is on by default. The speaker button on any open tool mutes every tool.
  • Student view. Students run their own copy of the saved timer stack. Your copy is the one on the board.
  • Technique spinner. Scans a block's text and only spins through the techniques it found, not all 310. Teacher picks the prompt: find it in the extract, or use it in your writing.
  • Timer presets. Teacher only. One tap loads a saved stack, like Think, Pair, Share.
  • Stopwatch, coin flip and scoreboard. Students also get the stopwatch, coin and technique spinner. The scoreboard stays with the teacher.
  • Countdown header. A header block for the assessment page, counting school days to the due date.
  • Names, numbers, groups and dice. Picked names can drop out so nobody is called twice.

Sample names only. Who was picked is not saved anywhere. It resets when you close the tool.
