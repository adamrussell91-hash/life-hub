# Food Journal world map

Add Map beside Timeline so someone can browse their saved visits geographically. Start at world scale, cluster nearby venues, and open journal entries from a venue's visit list.

Use the existing MapLibre basemap and a local GeoJSON layer for clustering. The individual venue embed remains available on entry pages. The map and venue picker use live visits with valid saved coordinates from the authenticated journal. The picker also provides keyboard access and works if the basemap fails.
