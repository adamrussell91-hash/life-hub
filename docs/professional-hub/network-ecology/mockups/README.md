# Network Ecology miniworld mockup

`miniworld.html` is the interactive design reference for `../BUILD-PLAN.md`.
Open it in a browser. It runs on 33 made-up people, so every name,
organisation and number is a placeholder.

Where the mockup and the build plan disagree, the build plan wins. The plan
adds a key, open sea and sandbank, N-segment shells, and a computed layout.
