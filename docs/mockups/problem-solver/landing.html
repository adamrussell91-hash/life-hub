    How a session builds

    The order follows the toolkit's problem solving process.

    1 · FRAME

    Three questions

    What is the goal, what is true, and what can be done. Each answer drops a piece into place.

    2 · DEFINE

    The coach picks a tool

    5 Whys for one clear symptom, a problem tree when causes tangle. The chart draws as you answer.

    3 · SKILLS

    Thinking you used

    Each answer earns the book's thinking skill marks, so you can see which ones you lean on.

    4 · DEFINED

    A record you can act on

    Finish with SMART objectives and a black and white record of every step.
