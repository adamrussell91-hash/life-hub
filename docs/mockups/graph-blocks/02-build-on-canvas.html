Build on the canvas

Work on the map itself. Click an idea to get a small toolbar next to it, use the + handle to grow a branch, drag to move things, and drag from a concept’s dot to another concept to link them. Branches taper like a hand-drawn map.

Editing a mind map

On desktop Art and propaganda starts selected. Try + to add a sub-idea, double-click to rename, or drag a branch and its sub-ideas move with it. Tidy lays everything out again.

Editing a concept map

Pre-opened: the link label editor, with verb suggestions. Drag the blue dot on any concept to another concept to start a new link, then pick or type the verb.

What students see

The map fits the frame when it opens, with no grey zoom buttons. Students can pinch or use full screen to look closer.

What changes, what stays

  • Same block data, plus position. Nodes keep { id, label, parent_id } and add the optional color, x and y that Teaching’s schema already allows. Tasks would add the same three optional fields. Blocks with no saved positions get laid out automatically.
  • Same block shell. The grip, ⋮ menu, Done, autosave and publish checks don’t change. This replaces Tasks’ form rows and reskins Teaching’s existing canvas engine with kit controls (no more raw grey zoom buttons or the empty pill top-left).
  • Phone. Tapping an idea opens a docked bottom sheet: a 16px name field, ≥44px actions and safe-area padding. In the hub it sits above the tab bar.
  • Trade-off. It’s more expressive, but the layout is yours to keep tidy, and big maps need pan and zoom on a phone.
