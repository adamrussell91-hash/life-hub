Outline → Map

Write it like notes, and the map draws itself. A mind map is an indented outline. A concept map is a list of concepts and the sentences that link them. You never drag, zoom or tidy anything.

Editing a mind map

Type in the outline. Tab makes an idea a sub-idea, and each branch keeps its own colour. Click a box on the map to jump to its line.

Editing a concept map

Each link is a sentence: Imperial propaganda — built → Ono’s reputation. Pick both ends from your concepts and write the verb, or tap a suggestion. A link with no verb gets an orange underline, because a concept map can’t be published without one.

What students see

The whole map fits at its real size, with no zoom buttons and nothing cut off. On a phone the mind map changes to a top-down tree rather than shrinking.

What changes, what stays

  • Same block data. Nodes stay { id, label, parent_id } and links stay { from, to, label }. The outline is just another way of editing parent_id, so existing blocks open as they are.
  • Same block shell. The grip, ⋮ menu, Done, autosave and publish checks don’t change. Only the editor inside the block and the drawing change.
  • One renderer. Tasks and Teaching would share one drawing function for the editor, the student view and print. Today Tasks has a form with an SVG preview and Teaching has a separate drag canvas.
  • Trade-off. You can’t place boxes by hand. The layout is always automatic.
