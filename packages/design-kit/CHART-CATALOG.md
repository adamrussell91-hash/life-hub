# Chart / graph catalog — design-kit source of truth

**When you need a new graph or chart**, open this file first. Pick an existing type. Do not invent a look that is not listed here.

This is the flat **selection** catalog (purpose, limits, where used, code paths). For APIs, tokens, locked look, and the change log, also read [`CHARTS.md`](./CHARTS.md). Implementation roots stay there; this table answers *which* type.

**Research notes (general practice):** Sankey ≈ ≤8–10 nodes/stage before spaghetti; chord ≈ ≤12 categories; streamgraph ≈ 5–15 layers; radar ≈ 5–8 axes / ≤4–5 overlays; waffle ≈ ≤3–4 categories on a 100-grid; pie/donut ≈ ≤5–6 slices; force/node-link degrade past a few dozen interactive nodes without clustering; Gantt stays readable when filtered to the audience’s critical path—not every micro-task. Cite those families in the rows below; hub-specific ceilings are local.

**Inventory base:** hub chart-types inventory (2026-09-30) + call-site verification on this branch. Documented-only rows (vis-timeline) are included on purpose.

## Selection cheat sheet (short)

| Need | Prefer | Avoid / second choice |
|---|---|---|
| Single KPI vs target | Progress ring; CSS progress track for thin chrome | Pie for one number |
| Waist / weight toward a goal band | **Glide slope** | Plain area-line alone |
| “How much already taken off the peak” | **Carved away** | Shed stack (weight kg story) |
| Several lead measures vs one threshold | **Gate rings** | Stack of thin progress tracks |
| Recomp “in the box” by date | Twin clocks + recomp plane | Two unrelated line charts |
| Rank / who’s improving | Bump | Absolute area-line |
| Theme mix over weeks | Stream (composition) or mood-mix (share now) | Chord for time |
| Transitions / co-occurrence | Sankey (directed volume); chord (peer links) | Force graph for simple A→B volume |
| Project journey / due pressure | Transit lines / flowchart lanes / orbit radar | Force graph on Tasks |
| Schedule & critical path | Plan timeline (Tasks) or scope Gantt (Teaching) | Almanac (capacity, not task Gantt) |
| Dense clinical snapshot | Meter / range-bar; zoned trend for history | Nested rings for many unrelated markers |
| Network explore | Force graph / miniworld / solar (Knowledge) | Chord for sparse sparse pairs |

Helpers that are **not** chart types: `animate`, `scene`, `polar-clock`, `clinical-slots`, `d3-layout`, `masonry`.
